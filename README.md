A traffic jam as a herd of metal elephants napping in the middle of the road — what the metaphor maps (the slow shuffle, nothing passing) and what it leaves out (no car is sleepy; each is stuck because the road ahead is already full).

## Run it

```sh
python3 main.py
```

This writes the two-line entry to `/output/entry.txt` (259 characters, 2 lines, no trailing newline).
